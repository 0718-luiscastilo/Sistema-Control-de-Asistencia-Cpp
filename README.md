# Sistema de Control de Asistencia en C++

## Descripción
Aplicación de consola desarrollada en C++ que permite gestionar la asistencia semanal de empleados, calculando asistencias, faltas y estado de desempeño.

## Funcionalidades
- Registro de empleados
- Captura de asistencia (A/F) durante 5 días
- Validación de entradas
- Cálculo automático de:
  - Asistencias
  - Faltas
  - Estado (Puntual, Regular, Irregular)
- Generación de reporte final

## Tecnologías
- C++
- Programación estructurada
- Arreglos (unidimensionales y bidimensionales)
- Control de flujo (if, for, do-while)
- 
## Objetivo
Practicar lógica de programación aplicada a un caso real de control de asistencia empresarial.
